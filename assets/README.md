# Изображения сайта BYTTEHMD

Загрузите все изображения в эту папку через **Add file → Upload files**.

## Логотип вместо буквы B

Файл:

```text
logo-byttehmd.jpg
```

Он будет использоваться в маленьком квадрате слева от названия BYTTEHMD.

## Главное изображение

Файл:

```text
hero-appliance.jpg
```

Это изображение используется в большом визуальном блоке на главном экране.

## Фотографии техники

```text
miele-k2912i.jpg

aeg-fse6370.jpg

siemens-iq300.jpg

neff-n70.jpg
```

Соответствие карточек:

- `miele-k2912i.jpg` — холодильник Miele K 2912 i
- `aeg-fse6370.jpg` — посудомоечная машина AEG FSE 6370
- `siemens-iq300.jpg` — стиральная машина Siemens iQ300
- `neff-n70.jpg` — варочная панель Neff N 70

## Рекомендации

- используйте латинские буквы и дефисы;
- не используйте пробелы в названиях;
- расширение файла должно совпадать с расширением в HTML;
- оптимальный формат — JPG или WebP;
- для карточек подходят изображения примерно 800 × 800 px;
- для hero-блока — примерно 1200 × 1600 px.

Итоговая структура:

```text
bytteh-website/
├── index.html
└── assets/
    ├── README.md
    ├── logo-byttehmd.jpg
    ├── hero-appliance.jpg
    ├── miele-k2912i.jpg
    ├── aeg-fse6370.jpg
    ├── siemens-iq300.jpg
    └── neff-n70.jpg
```
