# Папка для изображений

Положите изображения в эту папку с такими именами:

- `hero-appliance.jpg` — большая фотография для главного экрана
- `miele-k2912i.jpg` — фото холодильника Miele K 2912 i
- `aeg-fse6370.jpg` — фото посудомоечной машины AEG FSE 6370
- `siemens-iq300.jpg` — фото стиральной машины Siemens iQ300
- `neff-n70.jpg` — фото варочной панели Neff N 70

Поддерживаются JPG, PNG и WebP. Если используете другое расширение, измените его и в `index.html`, например `hero-appliance.webp`.
